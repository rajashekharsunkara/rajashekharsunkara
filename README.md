# Rajashekhar Sunkara

I'm a backend and AI engineer. I build Python systems end to end, from the data model and API through deployment, in Django, Flask or FastAPI.

Most of my recent work is where language models meet systems that have to be dependable. My approach is to keep the model out of the decisions: deterministic tools make the call, the model explains and drafts, and nothing it produces is trusted without a check.

I care just as much about the parts that don't demo well. I treat every input as hostile, test against a real database instead of a mock, and deploy and run what I build myself.

## What I've built

**[CloudGuard](https://github.com/rajashekharsunkara/cloud-guard-ai)** reviews infrastructure code for security problems. Checkov finds and scores the issues, then a language model explains each one and writes the patch, using similar past fixes from pgvector as examples. It runs on AWS, and also as a CLI and a GitHub Action. [Try it live](https://cloud-guard-ai.duckdns.org).

**[FireCloud](https://github.com/rajashekharsunkara/firecloud)** is encrypted storage spread across machines you own. Files are chunked and encrypted before they leave the client, and erasure coding keeps them readable after a third of the nodes go offline. [On PyPI](https://pypi.org/project/firecloud-devnet/).
